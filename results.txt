## Run 1: UZS-trained, evaluated on Chagatai test set
Date: 2026-06-30

Setup:
- Trained on: South Uzbek (UZS) dataset
- Evaluated on: Chagatai test set (data/CHAGATAI)
- Optimizer: Adam, lr=0.002000, betas=(0.9, 0.9), eps=0.000000, weight_decay=0.0

Eval data:
- eval csv: /kaggle/input/datasets/nurikw3/chagatai-test/test_final.csv
- eval samples: 59
- eval stanza files: /kaggle/working/stanza_uzs/chagatai_test
- Test samples: 59

Metrics:
- Token boundaries:    precision=0.9995  recall=1.0000  f1=0.9997  tp=1960 fp=1  fn=0
- Sentence boundaries: precision=0.6807  recall=0.4655  f1=0.5529  tp=81   fp=38 fn=93
- Sentence exact match: 2/59 = 0.0339

Metrics saved to: /kaggle/working/stanza_chagatai_eval_metrics.json

Notes:
- Token-level segmentation transfers very well from UZS to Chagatai (f1=0.9997).
- Sentence-level boundary detection transfers much more weakly (f1=0.5529), and
  exact sentence match is very low (3.4%) — cross-lingual transfer helps at the
  token level but is not sufficient on its own for sentence boundaries.

Notes:
