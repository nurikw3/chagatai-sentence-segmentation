# Notebook Archive

`stanza.ipynb` is the active Kaggle notebook. This folder stores snapshots of
experiment plans so previous waves can be reproduced after `stanza.ipynb`
changes.

## Naming

Use:

```text
YYYY-MM-DD_runN-M_short-description.ipynb
```

Example:

```text
2026-07-02_run11-15_nocharlm_seed7_followup.ipynb
```

Commit each notebook change with a message that names the experiment wave and
the reason for the change.
